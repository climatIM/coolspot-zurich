# US-15 · Edit place information

**Priority:** Should · **Milestone:** M2 · **Depends on:** US-08

## Story
As a **student**, I want to correct or complete a place's visitor information, so that others get accurate details (price, shade, toilets …).

## Acceptance criteria
- [ ] "Edit place information" opens a form for the visitor-info fields (price, cost details, opening hours, shade, amenities, access restrictions) and, for **custom places only**, the name.
- [ ] Anyone can edit anonymously; changes appear immediately.
- [ ] Only submitted fields are updated; last saved value wins.
- [ ] Edits never change assessments, categories, coordinates or Google Place ID.
- [ ] Google data is never overwritten: community corrections to Google-sourced values are stored separately and labelled as community data.
- [ ] Input rules from README apply; failed saves keep input and don't report success.

## Out of scope
Deleting places/assessments/comments, edit history, admin tools.
