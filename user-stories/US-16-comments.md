# US-16 · Comments

**Priority:** Should · **Milestone:** M2 · **Depends on:** US-08

## Story
As a **student**, I want to read and write short comments on a place, so that I can share tips (e.g. "best seats are on the 2nd floor").

## Acceptance criteria
- [ ] "Add comment" posts an anonymous plain-text comment (1–500 chars, trimmed); it appears immediately and persists.
- [ ] Each comment shows "Anonymous" and posting time.
- [ ] Newest 5 shown first; "Load older comments" loads more.
- [ ] Comments never affect coolness or other aggregates.
- [ ] HTML/scripts in comments are displayed as text, never executed.
- [ ] No per-user limits; normal validation only.

## Out of scope
Deleting, hiding, moderating or voting on comments; bot detection.
