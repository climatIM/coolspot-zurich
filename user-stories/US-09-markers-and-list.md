# US-09 · Markers, legend & list sync

**Priority:** Must · **Milestone:** M1 · **Depends on:** US-07, US-08

## Story
As a **student**, I want markers that show how cool each place is and stay in sync with the list, so that I can scan the map quickly.

## Acceptance criteria
- [ ] Marker style reflects the **cooling band** (4 levels); unrated places use a neutral style; the selected place has a distinct style.
- [ ] Band is also shown as text (e.g. in the legend/tooltip), not only by color.
- [ ] Legend explains all marker styles.
- [ ] Results list and markers always show the same set.
- [ ] Selecting a marker **or** a list entry opens the same details and highlights the place in both.
- [ ] Closing details keeps the current list, filters and map position.
