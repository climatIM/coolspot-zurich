# US-03 · Full-page map & layout shell

**Priority:** Must · **Milestone:** M1 · **Depends on:** US-01

## Story
As a **student**, I want a full-screen map of the city of Zurich with all main controls at hand, so that I can start looking for cool places right away.

## Acceptance criteria
- [ ] Google Map fills the desktop viewport and initially frames the **city of Zurich**.
- [ ] Filters, the marker legend and (if US-17 is built) search are always reachable.
- [ ] A side panel hosts results and place details.
- [ ] The city boundary is available to the app for eligibility checks (used by creation and search stories). The map itself may be panned beyond the city.
- [ ] **No** "Use my location" control and no user-position marker.
- [ ] App name "CoolSpot Zurich"; English UI; currency CHF.
- [ ] Polished desktop style: one consistent font throughout (developer's choice), readable controls, cooling and cost info visually prominent.
