# US-11 · Browse all places

**Priority:** Must · **Milestone:** M1 · **Depends on:** US-09

## Story
As a **student**, I want to see all saved places in the current map area, including unrated ones, so that I can explore beyond the top picks.

## Acceptance criteria
- [ ] A **"Browse all places"** control shows all saved POIs within the current view and active filters.
- [ ] Order: rated places by coolness order, then unrated places by name, then stable ID.
- [ ] List paginated in batches of 10 ("Load more"), no repeats; markers and list in sync.
- [ ] Only saved POIs are shown – not every Google business.
